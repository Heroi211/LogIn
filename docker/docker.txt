Stack backend (API + PostgreSQL + pgAdmin)

Subir tudo:
  make up

Reset completo (volumes + rebuild):
  make docker-fresh

Build manual (alternativa):
  docker build -f docker/db.dockerfile -t login_database:v1 .
  docker build -f docker/api.dockerfile -t login_api:v1 .
  docker build -f docker/pgadmin.dockerfile -t pgadmin_db:v1 .

Ou:
  docker compose up --build

Endpoints:
  API:     http://localhost:8000/docs
  pgAdmin: http://localhost:5050
